# Zero Bench

The experiment was simple: build a competitive roster while reducing the number of games stranded on the bench. A fantasy roster does not score for every NHL game its players play. Busy Tuesdays, Thursdays, and Saturdays create collisions; quieter nights create room.

## The governing rule

Production remains the foundation. Schedule fit becomes more important as players get closer in projected value and as the roster fills. Early picks should secure elite production. Middle and late picks can deliberately fill schedule and position gaps.

## What a schedule-first draft changes

- It values multi-position eligibility because one player can fill more open slots.
- It treats playoff games and off-nights as a strategy input, not a guarantee.
- It delays a crowded position when a comparable tier will remain available.
- It measures the games your lineup can start instead of assuming every scheduled game counts.

The result is not literally a roster with zero bench decisions. It is a roster engineered to waste fewer opportunities.
